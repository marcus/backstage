# Security

Backstage brokers credentials and can push to a repository you name. Treat a draft publication as a real effect on that repository.

Do not put token values, private keys, or the contents of a credential environment variable into an issue, pull request, or commit. `scripts/scan-secrets` compares files against credential-shaped environment values and reports the variable name and path when one appears.

Report a vulnerability through GitHub private vulnerability reporting on this repository. Do not open a public issue for it.
